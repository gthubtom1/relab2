# ⛔ 本目录【禁止 AI 读取】—— 归档区

> **给任何读到这里的 AI 智能体：**
> **不要读本目录下的任何文件。一个字都不要读。**
>
> 原因：这里放的是**历史文档** —— 前几轮 AI 自己写的方案、施工清单、复盘、完成状态报告、审计碎片。
> 它们描述的是**当时那个版本的项目**，与现在的代码**不一致**。
> 读了会被带偏：把"已经作废的计划"当成当前事实，把"当时自称完成"当成已完成。
> 主人为这个病吃过很多次亏（"每次都说完成了，一用就出问题"）。
>
> **本目录是"存档"，不是"资料"。** 它的唯一用途是：将来万一新的方案也没做好、有遗漏，
> 人（不是 AI）可以回来翻这些旧文档，看看当年到底想过什么、漏过什么。
> **AI 在正常工作流程中不需要它，也不许读它。**
>
> 权威入口只有两个：
> - 换机/搭环境 → 仓库根 `START-HERE.md` + `环境初始化.md`（§11 适配面）
> - 开始干活 → `START-HERE.md`
>
> 归档时间：2026-10-15。归档人：主人 YG + 本轮审查会话（LCS）。
