# 为什么要归档这两份（旧 05 / 旧 06）

它们抄错了地方，且违反了本包自己的两条硬规矩：

1. **旧 06 写死了「运行时探测出来的本机路径」**（如某个 Python 版本目录下的 `capa.EXE`）——
   违反 `环境初始化.md` §10：**探测到的运行时路径不许写进任何文档**（换机即失效，写下来就是埋雷）。
2. **旧 06 的「四步剧本」是固定流程** —— 违反铁律①：技能内容不许编排 `Step 1 → Step 2 → Step 3` 任务流程。
3. **旧 05 的「目标 → 第一工具直通表」本包本来就有，而且更细**
   （`skills/reverse-engineering/references/signal-to-tool-decision.md` + `assault-entry` Q0–Q3），属于白抄。

**取代它们的**：`docs/lcs-core/05-REA可借鉴的四条工程写法.md`（记 REA 真正值得抄的四条，以及明确不抄什么）。
