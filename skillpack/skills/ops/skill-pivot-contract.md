# 换技能契约（全包唯一事实源）

> **用途**：所有 SKILL.md 的 `## When to Pivot` 段指向本文件的触发条件，各技能只列**自己的去向表**。
> 来源：判据表 B 组（`work/plan-v3/02-判据表-可固化与禁固.md`）。
> **这是契约，不是流程。** 它规定"出现什么信号必须重新判断"，不规定"按什么顺序做"。

---

## 触发换技能的七类信号（任一命中即须重新选技能）

| # | 信号 | 依据 |
|---|---|---|
| 1 | **决定性新证据**：判出壳/语言/框架/协议/保护器/服务端依赖 | Votipka N=15；本项目常驻卡 §4 |
| 2 | **工具或环境报错且说不通** | 说不通 = 入口不是障碍 |
| 3 | **静态与动态结论矛盾** | 矛盾即入口，不许挑顺眼的信 |
| 4 | **同一假设连续两次尝试无新证据** | ADF-R43；PMA"别在单点耗太久" |
| 5 | **成本比反转**：静态还需 ≥数小时 vs 动态一次 ≤分钟级 | SOUPS'24 P23 原话 |
| 6 | **任务进入新域**（开发中突然要逆向/渗透/抓包） | 本项目常驻卡 §4 |
| 7 | **耗时估计超出目标可承受** | FIRST Phase 4 |

## 换技能时必须做的一件事

timeline 记一行：

```
换技能：<旧技能> → <新技能>，因为 <信号编号 + 一句证据>
```

## 换技能的判据来源

换之前 MUST 查 `../ops/analysis-decision-framework.md` 的 **R2 / R31 / R43**（假设驱动退出 / 阶段偏执自检 / 计划死锁重规划）。

## 各技能的用法

SKILL.md 里只写"我不适用了 → 换谁"，例如：

```markdown
## When to Pivot

信号与判据见 `../ops/skill-pivot-contract.md`。本技能去向：
| 触发证据 | 换到 |
|---|---|
| diec 报 VMP/Themida | `../reverse-engineering/references/assault-entry.md` |
| 目标实为 .NET | `../dotnet-reverse/SKILL.md` |
```
