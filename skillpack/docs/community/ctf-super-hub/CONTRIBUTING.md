# 贡献指南

感谢你愿意改进这套 CTF skills 整合包。

## 建议贡献类型

- 修正文案、拼写、术语说明
- 提升新手友好度
- 优化 `ctf-super-hub` 的路由与输出模板
- 补充 README / 文档 / 示例
- 增强校验脚本和 CI

## 提交建议

1. 新建分支
2. 改动尽量聚焦
3. 若修改 skill 路由逻辑，请同步更新文档
4. 提交前运行：

```bash
python3 scripts/validate_skills.py
```

## 文案约定

- **名称和简介尽量中文化**
- **触发名不汉化**
- 对新手优先使用直白中文，而不是只堆术语
- 如果术语不可避免，尽量提供一句人话解释

## 对 skill 的修改原则

- 尽量保持目录名不变，避免破坏触发名和已有引用
- 新增内容优先放在 `references/` 或仓库级 `docs/`
- 不要随意删除原 skill 中的上游字段

## Pull Request 建议内容

请说明：
- 改了哪些文件
- 为什么改
- 对使用方式有什么影响
