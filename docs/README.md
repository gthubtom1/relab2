## 五、历史件（**退出依据链**：可以读，不许当现行事实）

`docs/_history/` 下的所有文件、以及 `_snapshots/` 下的快照，描述的都是**写下它的那一刻**。

典型例子：`_history/AUDIT-2026-10-15-*.md` 的「本机没有 Node.js」现在是错的
（实测 `node -v` = `v22.23.3`）。**要引用它的数字，先自己复算。**

**进度与剩余不再以任何单篇「完工交接」为准** —— 那东西一定会腐烂。现在的判据是：

```bash
python work/_benchmark/final_acceptance.py     # 63 路由六项验收
relab2.ps1 doctor                              # 本机配置就绪度
python skillpack/skills/tests/run-ci-gates.py  # 45 道门
```

## 六、⛔ 禁止 AI 读取

`_归档-禁读-历史文档/` —— **一个字都不要读**。

那是留给**人**的存档（前几轮 AI 的方案 / 施工清单 / 复盘 / 「完成状态」报告），
描述的是**当时那个版本**，与现在的代码不一致。读了会把「已作废的计划」当成当前事实、
把「当时自称完成」当成已完成。

口令与理由见仓库根 [`START-HERE.md`](../START-HERE.md) 开头的硬禁令，以及该目录自己的 `README-禁令.md`。

## 七、冲突裁决

任何文档、注释、历史 rules 与下面两个冲突时，**以它们为准**：

1. [`../START-HERE.md`](../START-HERE.md) —— 干活入口
2. [`../环境初始化.md`](../环境初始化.md) §11 —— 换机适配面

两份**令**（HANDOFF / ASSESS）继续管它们各自的主题：**方法**以 HANDOFF 为准、**验收判据**以 ASSESS 为准。
「退出依据链」指的是 —— **里面的实测数字与「已完成」结论不得直接引用**（先自己复算），
不是否定它们作为「令」的身份。**令管方向，数字要复算。**
