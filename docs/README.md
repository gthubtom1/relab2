   完整适配清单在 [`../环境初始化.md`](../环境初始化.md) **§11**（§11.1 适配面 / §11.5 第一天顺序 / §11.7 新组件）。
2. **开始干活** → [`../START-HERE.md`](../START-HERE.md)。
3. **施工总令（方法）** → [`HANDOFF-终极交接与施工任务书-全AI通用.md`](./HANDOFF-终极交接与施工任务书-全AI通用.md)。
4. **需求档案（灵魂）** → [`lcs-core/`](./lcs-core/)：`00` 总章、`01` 老板原话、`02` 终极需求、`03` 为什么旧模型偏航、`04` 业界方法论。
5. **完工台账 / 剩余清单** → [`FINAL-彻底完工交接-2026-10-15.md`](./FINAL-彻底完工交接-2026-10-15.md) —— **进度与剩余以它为准**。
6. **独立审查结论** → [`AUDIT-2026-10-15-独立审查结论与修正指令.md`](./AUDIT-2026-10-15-独立审查结论与修正指令.md)。
