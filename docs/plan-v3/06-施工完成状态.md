## 预算重新标定（记录在案，不是无声放宽）

`check-prompt-budget.py` 的 `MAX_TOTAL_BYTES`：10000 → 16000。

**依据**（写进脚本常量上方注释）：
- Anthropic Issue #11045：宿主侧元数据预算约 15,500–16,000 **字符**；每技能约 109 字符固定开销；超限**静默隐藏且无警告**
- 57 技能 × 109 ≈ 6,213 字符开销；剩给内容 ≈ 9,287 字符 ≈ 27,861 B（硬上限）
- 取 16,000 B ≈ 5,333 字符内容 + 6,213 开销 ≈ 11,546 字符 < 15,500 → 留 ~25% 余量
- **为什么不继续压**：上一轮 A/B 已证伪"压缩 description 能提升触发"（压缩是吸引子，净效果 ≤0）。压到形状达标但触发失效，是反向优化。
