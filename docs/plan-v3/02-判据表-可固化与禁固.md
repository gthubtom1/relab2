# 判据表：可固化 vs 绝不能固化

> **本文件是"不要给模型预设固定流程"（R10）的落地依据。**
> 证据来源见每条后的链接。调研完成日：2026-10-14。
>
> **核心原则：固化的应是"判断依据"（什么情况下必须做什么判断），不是"执行步骤"（先跑什么后跑什么）。**

---

## 0. 一句话总纲

**三份独立人因研究 + 四份权威行业框架 + 三家厂商官方文档，全部指向同一结论：主循环不可流程化；只有"开局定向"和"卫生习惯"可以清单化。**

| 领域 | 权威框架自己怎么说 |
|---|---|
| 逆向 | Votipka USENIX'20：后两阶段**成环迭代**；RE-Mind：**"everyone has their own style"**；SOUPS'24：**"similar to an art form"** |
| 恶意代码 | FIRST：**"there is not one solution that fits all needs"**；Zeltser(SANS)：**"wash, rinse, repeat... 直到时间用尽"** |
| 渗透 | NIST SP 800-115：图标题就是 **"Attack Phase Steps with Loopback to Discovery Phase"**、**"reporting occurs simultaneously"**；OWASP WSTG：**"should not be seen as prescriptive"** |
| 攻链 | ATT&CK FAQ：**"ATT&CK Tactics are unordered"**；UKC：**"can occur in any order, loop back, or run in parallel"** |
| 取证 | NIST SP 800-86：**"not to be used as an all-inclusive step-by-step guide"**；ACPO：**"not... a how to do instruction manual"** |
| AI coding | Anthropic：**"Plan mode is useful, but also adds overhead... If you could describe the diff in one sentence, skip the plan"** |

## 1. ✅ 可固化的判据（触发证据 → 判据 → 动作）

> 全部有来源；全部是**条件式**而非**顺序式**。

### A 组：任何任务的开局定向（唯一存在稳定共识的一层）

| # | 触发证据 | 判据 | 动作 | 来源 |
|---|---|---|---|---|
| A1 | 拿到任何目标/任务 | **必须先有一个可回答的问题**；无问题则无法定义"够不够""何时停" | 先写下一句目标问题，再开工具 | FIRST Phase 3；Ryan Stortz goal-first |
| A2 | 未知格式/无法选工具 | 格式决定工具链与位宽 | 查 magic；PE→Win、ELF→Linux、.NET→dnSpy、脚本→解释器 | FIRST；HaiND |
| A3 | 已算哈希 | 已知样本无需重做 | 先查 VT/报告，命中则提取 IoC 并停 | FIRST Phase 2；PMA |
| A4 | 涉及执行且样本可疑 | 涉及执行即需隔离 | 隔离环境后再跑 | FIRST；SANS ISC |
| A5 | 未定位到"有趣代码" | strings/imports 是低成本入口 beacon | 从 strings 与 API xref 反查；**不要从入口盲读** | Votipka (N=15)；Ryan Stortz "不要从 main 开始" |

### B 组：换方法/换工具/换技能的触发器（R8 的机制）

| # | 触发证据 | 判据 | 动作 | 来源 |
|---|---|---|---|---|
| B1 | 换法候选：静态还需 ≥数小时 vs 动态一次 ≤分钟级 | **成本比阈值** | 立即切动态，用一次运行取事实值 | SOUPS'24 P23 原话 |
| B2 | 新 beacon 与既有假设冲突 | 假设被证伪 | 立刻停当前实验，回扫描改假设；**不许挑顺眼证据** | Votipka |
| B3 | 同一假设连续两次无新证据 | 停止投入，剪枝 | 回路线重选（= ADF-R43） | ADF-R43；PMA"别在单点耗太久" |
| B4 | 工具/环境报错且说不通 | 说不通 = 入口，不是障碍 | 停下查为什么，不许绕 | 本项目既有 |
| B5 | 静态结论与动态结论矛盾 | 矛盾即入口 | 两个都查，不许选一个顺眼的 | 本项目既有 |
| B6 | 任务进入新域（开发中突然要逆向/渗透/抓包） | 域变了，技能必须变 | 当场换，timeline 记一行 | 本项目既有卡 §4 |
| B7 | 分析耗时估计超出目标可承受 | 边际收益已低于成本 | 降级为 triage 产出，停止深挖 | FIRST Phase 4 |

### C 组：粒度控制（治"陷进杂草"）

| # | 触发证据 | 判据 | 动作 | 来源 |
|---|---|---|---|---|
| C1 | 目标未定/大程序/triage 阶段 | 先略读，别陷细节 | 只扫 beacon，不逐行 | Votipka P08V；RE-Mind 专家丢 22% 块 |
| C2 | 目标是复现算法/绕过校验且范围已小 | 需要精确理解 | **才允许**逐行；按基本块→指令粒度递增 | joxeankoret（RE SE） |
| C3 | 进入不熟悉的大代码库 | 需要全局定向 | 才做 overview（**小目标可跳过**） | RE-Mind：最快专家不做总览 |
| C4 | 已能判断某基本块无关 | 决定忽略什么 | 丢掉它，不做完整遍历 | Brown 2024 "determining what to ignore" |

### D 组：证据与验收（治"改好了不可证伪"）

| # | 触发证据 | 判据 | 动作 | 来源 |
|---|---|---|---|---|
| D1 | 任何改动完成前 | **必须存在一个 agent 能自己跑的 pass/fail check** | 测试/build/lint/screenshot diff；没 check 不许说完成 | Anthropic 官方（唯一强共识） |
| D2 | 主张"做完了" | 必须附证据（测试输出/命令返回码/截图） | 禁止只下结论 | Anthropic；Simon Willison |
| D3 | 结论要标 validated | **≥2 独立证据**（最好 1 静 1 动） | 单条不得静默升级，留 candidate + residual | ADF-R4*；evidence-finding-path |
| D4 | done 判定 | verified（有证据）+ reviewed（人看过）+ deployable/shipped | 三元缺一不算 done | Fowler；Agile Alliance；Scrum.org |
| D5 | 一个 CL/一次改动 | one self-contained change、~100 行量级、测试同 CL、不破构建、重构独立 | 太大 reviewer 有权直接拒 | Google Small CLs |
| D6 | 复核 agent 报告 | 只采纳影响**正确性或需求**的问题 | 其余标 optional，防 over-engineering | Google + Anthropic 官方警告 |

### E 组：成本与难度（治 Type B 58%）

| # | 触发证据 | 判据 | 动作 | 来源 |
|---|---|---|---|---|
| E1 | 准备深扎一条路前 | **估计还需多少步 + 当前证据置信度** | "3 步还是 30 步"答不出 → 先补侦察 | arXiv 2602.17622 TDA 四维 |
| E2 | 上下文占用升高 | 常驻证据丢失率与 phase 数成反比 | 传 artifact 不传对话；子 agent 只回 1–2K 摘要 | arXiv 2608.21423 Rule 1 |
| E3 | 侦察到死但不下手 | 探索-利用失衡 | 强制转入一次最小验证实验 | arXiv 2602.17622 |

## 2. ❌ 绝不能固化的（附"固化为何造成伤害"）

| # | 不可固化 | 伤害 | 证据 |
|---|---|---|---|
| N1 | **分析主循环的固定步骤序列** | 锁死单一顺序，错过最优 middle-out；忽略"目标不同→流程不同"（5 种工作流） | CCS'21；SOUPS'24；RE-Mind |
| N2 | **"必须先总览全局"** | 小目标上纯浪费；**最快专家恰恰不做总览**；诱导分析瘫痪 | RE-Mind 原文；Votipka 5 人跳过 |
| N3 | **"必须从 main/入口开始"** | 大型程序 main 离目标太远 | Ryan Stortz 原文；Votipka P03V |
| N4 | **"必须逐行读完函数"** | 常见错误，陷在单指令/flags 上忘了真正问题 | joxeankoret 原文 |
| N5 | **工具选择写死** | 方法应由"分析师强项+目标+样本特征"决定 | SOUPS'24 P11；FIRST "no perfect setup" |
| N6 | **"先做 X 后做 Y"作为硬规则** | 溯因循环的下一步由"当前最大不确定点"决定 | Brown 2024；Votipka "results feed back" |
| N7 | **固定退出阈值**（"必须分析满 N 小时"） | 深度应由问题集合与成本比决定 | FIRST（深度∝问题数） |
| N8 | **CTF 套路迁到真实目标** | CTF 已知有解、空间收敛；真实目标开放且常无解 | AutoPenBench 批评 gamified；REStack 32% |
| N9 | **清单勾选 = 分析完成** | 制造"已覆盖"虚假安全感，掩盖未识别未知 | Paragonie "Checklist-Driven Security Considered Harmful" |
| N10 | **固定"先写测试"（全局强制 TDD）** | 实验显示 agent loop 内无增益甚至略负、token 3–8x；根因是阻止了 upfront design | Böckeler 对照实验（Fowler 站） |
| N11 | **固定测试比例（80/15/5 / trophy 形状）** | Google 2024 自己说 "beyond the test pyramid"；Dodds 说纠结比例是 distraction | Google SMURF；Kent C. Dodds |
| N12 | **固定工具/框架/命令清单** | 换栈即失效；agent 已会 npm/git/pytest | Cursor 官方 best practices |
| N13 | **固定"何时必须问用户"触发点** | 官方判据是规模/不确定性驱动，不是步骤 | Anthropic：小任务直接做，大任务先 interview |
| N14 | **把 scope/budget 约束交给 prompt** | prompt 不是最后防线；LLM 在构造上处于 TCB 之外 | arXiv 2608.21423 |
| N15 | **"必须走完所有阶段"/phase 切得越碎越好** | 长会话证据丢失率与 phase 数成反比 | 同上；UKC "not all adversaries execute all phases" |

## 3. 矛盾说法与适用边界（都要保留，不许只留一边）

| 矛盾 | A 方 | B 方 | 边界 |
|---|---|---|---|
| 逐行 vs 略读 | Purism："逆向就是逐行顺序地读" | Votipka P08V / joxeankoret："别陷细节" | **A 用于已锁定、小范围、需精确复现**；B 用于大程序/目标未定/triage |
| 从入口 vs middle-out | 多数教程隐含从 main | Ryan Stortz："不要从 main 开始" | 小程序/教学 → A；大型/网络/固件 → B |
| 必须总览 vs 跳过总览 | Zeltser 金字塔；HaiND"前 10 分钟不读代码" | RE-Mind："最快专家不做总览" | 大代码库+不熟悉 → A；小题目/已熟悉同类 → B |
| TDD | Simon Willison / Anthropic：red-green TDD 有效 | Böckeler 实验：无差异、略负、3–8x token | 有明确行为规格/回归修补/小 → test-first；greenfield/设计敏感/大 → 先设计 |
| 阶段有序 vs 无序 | CKC 有序 | ATT&CK 无序；UKC 任意顺序 | 防御方叙事用 CKC；检测工程用 ATT&CK；战役复盘用 UKC |
| 方法论有用 vs 有害 | Johansen/Duffy："sticking to a methodology prevents tunnel vision" | Albrecht & Jensen《The Vacuity of OSSTMM》：固定步骤"may subvert the understanding of the target" | 目标与框架**高度同构**（普通 Web/网络）→ 方法论有益；目标**陌生/异质**（ICS/嵌入式/未知协议）→ 制造盲视 |
| CTF 有用 vs 不真实 | REStack：占社区 32%，学习价值真实 | Paxton-Fear / "What CTFs Don't Teach You" | 教学/练习 → 套路；真实目标 → 不可迁移 |

2. **`ops/analysis-decision-framework.md` 提上主链**：从"仅 Synthesis/stuck-loop 加载"改为"换阶段或换技能前必读 R2/R31/R43"。

5. **建回归表**：没有回归表，§1 的判据全是空话。
