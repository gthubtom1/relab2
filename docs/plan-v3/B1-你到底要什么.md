# 第二部分：那么，你要的"成品"是什么样

把你所有话收拢，我理解你要的成品是**三个"能"**：

### 能一：**能自己找路**
给一个软件，它自己分析、自己判断该用什么技能、自己换技能、自己配工具 ——
**不需要你提示**（现在需要你提示三次：抓包、脱壳、反反调试）。

### 能二：**能自己验证**
它说"做完了"的时候，**你能信**。不是它说、不是报告厚、不是门禁绿，
而是有一个**它自己跑得动、你也看得懂**的东西证明它做完了。

### 能三：**换地方就能用**
换新机器、换别的智能体，走一遍适配流程就能干活，**不需要再理解一遍项目**。

**三条都成立，才叫"完成"。** 缺任何一条，[10] 说的那个循环就还在。
