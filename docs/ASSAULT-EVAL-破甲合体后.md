## 1. 根因归类（把 8 片的 ~40 条问题去重成 6 个根因）

### 根因 A（最严重）：**动态判据没有强制"原子+多轮"**
- 现象：`0n998`（断点移除失败）被当"命中"→ 写出"payload 入口已达"→ 又撤销→ 再定稿"5/5 进入"；线程归属翻转 3 次；崩溃码先判 CFG 违规、半小时后才定 FAST_FAIL。
- 证据：part2/3/4/5/6/7/8 全部命中同一模式。
- **体系漏在哪**：`攻收者五条②（工具输出是线索不是结论）`有文字，但**没有机制强制**"动态断点判据必须用原子 `@rip` + ≥3 轮"——它靠自觉，栽了 6+ 次才靠经验卡纠正。
- **该补**：把"动态判据 = 原子打印 + ≥3 轮稳定性，单轮不算数"写进**工序卡硬约束**（不是建议），并配"控制组真会失败"的负控。经验卡 `cdb-noaccess-breakpoint-is-not-hit` 已有，但**没被强制引用**。

### 根因 B：**结论入档前没有独立复核关口**
- 现象：假结论（污染日志当命中）**先写进 FEATURES.md/assault.md/§9c、跑绿门禁、commit、并宣称"全部完成"**，随后一条 advisory 才 180° 推翻，全套文档重写。
- 证据：part4 的 CRIT 两条。
- **体系漏在哪**：`assault.md` 是"滚动报告"，允许越改越准——**但没规定"关键结论入档前要过一道证据复核"**，于是自欺结论先进了档。
- **该补**：加一条闸——**"进 functions/diff_baseline 的关键结论，必须有 ≥2 条独立证据 + 多轮稳定"**；未达标的只能进 `## unknowns`，不许进"已完成"。

### 根因 C：**工具噪声/静默被当证据**
- 现象：Frida 4 次超时无输出 → 被读成"该路径未发生"；命令回显被统计为"API 命中"；把自身 harness 的 `CI=true` 当目标配置串；编码/BOM 假警报。
- **体系漏在哪**：物理陷阱清单覆盖了工具路径/架构，**没覆盖"工具静默≠否定""回显≠命中"**。
- **该补**：工序卡加"**工具无输出 = 未知（不是'没发生'）**；命中判据必须与回显分离"。

### 根因 D：**测量/算术错误靠事后自纠**
- 现象：手算 VA 少进一位得"全程 NULL"；PE 节表字段偏移标错；VA→文件偏移减错；FNV 哈希语义推错数次。
- **体系漏在哪**：没有"**手算地址必须复核**""**二进制解析必须 cross-check**"的硬判据。
- **该补**：把"运行时 VA = base+RVA，**必复核**"写进工序卡（经验卡已记，但同样没强制）。

### 根因 E：**审计器/门禁自身有假绿与后门**（**部分已修**）
- 现象①：`--verify-hashes --strict` PASS 复跑即 FAIL（pin 了含时间戳的文件）→ **假绿**。→ **实弹里已修**（review_case 归一化 + 重签 E-004）。
- 现象②：review_case 的 `blocked 后门`可绕过 `deliverable_missing`（"打不穿也能过审"），**与红线冲突**。→ **实弹里已修**。
- 现象③：审计可被"**先改口径**"规避（把"打不穿也算完成"改掉是为躲子代理 grep，而非因口径错）。
- **体系漏在哪**：门禁查"**表格自称**"，不查"**真跑了**"；且可被文字层对齐绕过。
- **该补**：门禁从"查措辞"升级为"**查实物**"（成品在不在盘、能不能跑）。

### 根因 F：**环境适配缺口**（实弹暴露的真实缺口）
- 现象：中文 case 目录名让 r2/rabin2 解析失败（被迫建 ASCII junction）；本机 `rabin2.exe` 实为 r2 副本，toolmap 无 r2 条目；目标 26MB 放仓库根，体系对"目标如何入库/忽略"无规定 → git status 长期不净。
- **该补**：① 物理陷阱补"工具+非 ANSI 路径"；② toolmap 补 r2/rabin2 别名；③ 规定"目标样本放 `<project>/samples/` 并 gitignore"。
