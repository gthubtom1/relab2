   接受「需真实环境」的成品，还是这类目标本就该换验收口径？

3. **改名 + 假进程这两招够把控制流推进到 payload，说明门栓层不硬——硬的是 payload 层。**

   payload 主动把 `.text`/`.ace0` 页翻 NOACCESS，调试器再想读/设断点都被拒。
