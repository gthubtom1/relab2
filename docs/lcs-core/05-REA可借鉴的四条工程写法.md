## 一、先说结论：REA 真正值得抄的是「手」，不是「脑」

审计 + 逐文件对照之后的判定：

| 维度 | REA 的做法 | 本包原本有的 | 结论 |
|---|---|---|---|
| 「目标 → 第一个工具」直通表 | 约 15 条粗分支 | `references/signal-to-tool-decision.md` 决策树 + `assault-entry` Q0–Q3 + `MASTER-ROUTING.md` | **本包更细**，**不需要抄** |
| 决策判据 / 证据体系 | authority / limitations / coverage / unknowns 四件套 | `ops/analysis-decision-framework.md`（R1–R51 + `E-*` Evidence ID）、`evidence-finding-path.md`、`confidence-vocabulary.md` | **本包更厚**，**不需要抄** |
| **工具怎么递到模型手里** | 全封成 MCP 工具，模型工具列表里直接可见可调 | 让模型自己去 shell 找工具、起通道、拼命令行 | **REA 赢** → 已抄 |
| **第一屏形态** | 第一节就是 `Route the target first` | 第一节是「必须立即执行 4 步」契约 | **REA 赢** → 已抄 |
| **前置诊断** | 明确禁止每次调查前跑诊断 | 要求「动手前先执行 mcp-status.ps1」 | **REA 赢，且本包原写法是反的** → 已改 |
| 大结果处理 | summary-first + 落盘，别把大 JSON 灌进上下文 | 无明确纪律 | **REA 赢** → 已抄 |

**一句话**：REA 值得抄的是**「工具手边化 + 第一屏即路由 + 不做前置诊断 + 大结果不进上下文」**这四条工程写法 ——
**不是**它的路由表（本包本来就更细），**也不是**它的推理体系（本包本来就更厚）。

## 二、四条写法，各自落到了哪里（可逐条查证）

| # | 写法 | 落地位置 | 怎么验 |
|---|---|---|---|
| a | **工具手边化**：工具优先级 **MCP 通道 > CLI 孪生 > GUI**；后端只在被调用时拉起 | `skills/SKILL.md` 第一屏；`skills/scripts/mcp-lazy-http.py`（stdio·懒启动代理）；宿主 `mcp.json` 的 6 条通道（★ 2026-10-16 更正：写本文时是 5 条，之后加了 `rea`；**条数现查，别引用本行**） | 跑 `relab2.ps1 doctor` → 「MCP 通道自检」报每条通道的命令在不在、懒启通道有没有缓存/种子 |

| d | **大结果不进上下文**：超阈值先落盘再分页读 | `skills/SKILL.md` 命令纪律硬规则 | 搜「先落盘」 |

## 三、明确**不抄**的（省得后来人再纠结）

1. **不装 REA 本体**：本机（无 Node 时）装不了；即便装了，它只覆盖「看透」，不负责「交付成品」——
   那正是本包的主战场。
2. **不抄它的直通表**：本包已有的更细。
3. **不抄它的路由架构**：REA 是「单卡 + MCP 门面」；本包是「57 张卡 + 路由 + 中枢」，架构不同层级。
4. **不写死运行时路径**：旧 `06` 抄了个「D 盘工具绝对路径大底册」，违反 `环境初始化.md` §10
   （**探测出来的运行时路径不许写进任何文档**）。工具装在哪一律现场探测：
   `. <技能包根>\skills\scripts\lib\Bootstrap.ps1` → `Resolve-ReverseToolSpec -Name <id>`。

## 四、REA 的部署模型（值得对照，不必照搬）

它做对的几件事，本包已用不同方式对齐：

| REA |本包对应 |
|---|---|
| `npx rea-agents setup` 一条命令接入 | `relab2.ps1 setup`（仓根/环境变量/技能挂载/**MCP 注册**一条龙，`-DryRun` 可预览） |
| `rea doctor` 三层归因 | `relab2.ps1 doctor`（12 项；含 **MCP 通道真自检**：命令在不在、懒启通道有没有缓存/种子、装机卡有没有漂移） |
| 自动扫描本机支持的 23 个客户端 | `skills/scripts/register-skills.ps1`（一份实体 + N 个目录联接） |
| 升级走 `rea update` | `relab2.ps1 update`（git pull → 重跑 setup） |
