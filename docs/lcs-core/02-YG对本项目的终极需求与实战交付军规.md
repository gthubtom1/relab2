# 二、YG 的全域技术宏图（绝不仅是逆向）

这个项目 `relab2` 是 YG 唯一的**全局中央武器库与智能中枢**。未来 YG 的所有工作，只要挂上这个中枢，AI 就必须具备以下四大领域的真实作战能力：

```mermaid
graph TD
    Hub[relab2 全域中央武器库与智能中枢] --> Sec[1. 安全攻防与渗透测试]
    Hub --> Proto[2. 协议分析与算法逆向]
    Hub --> RE[3. 深度逆向与受保护目标攻坚]
    Hub --> Dev[4. 日常软件开发与运维交付]

    Sec --> |Web渗透/内网/API/云安全/工具链联动| SecWork[像实战黑客一样情报回流、动态寻找薄弱点]
    Proto --> |抓包/WebSocket/加解密/签名还原| ProtoWork[还原网络通信与核心算法]
    RE --> |PE/ELF/APK/脱壳/反反调试/Patch| REWork[目标驱动/动态换法/直奔可用成品]
    Dev --> |写功能/修Bug/重构/测试/自动化| DevWork[小步快跑/拒绝过度设计/真实运行验收]
```

### 1. 安全攻防与渗透测试
- 不死板走流程，情报动态回流；
- 熟练联动电脑上的扫描器、抓包工具、测试脚本，针对目标漏洞做精准打击。

### 2. 协议分析、抓包与算法还原
- 针对 Web、小程序、App、桌面端网络通信，抓包、脱壳、Hook、还原签名算法与 Token 校验；
- 提取通信逻辑，做出可独立复现的协议脚本。

### 3. 深度逆向与受保护目标攻坚
- 面对加壳、混淆、反调试、父进程检测、无凭据云端校验，像老手一样“Middle-out”逆向；
- 静态卡住立刻转动态，有壳脱壳，遇反调试过反调试，做出能跑、能用的成品。

### 4. 日常软件开发与运维交付
- 编写业务模块、重构代码、修复疑难 Bug、补齐自动化测试；
- 坚决杜绝把日常开发推脱为“以后再做”，必须作为一等公民完全就绪。

# 三、彻底完成的四大军规

1. **绝对不给模型设置死板流程**：
   任何软件和任务都千变万化，技能卡只提供触发信号、武器选项、换法门槛，绝不预设全局固化步骤。
2. **所有领域平权全面就绪**：
   安全、逆向、协议、开发所有领域全部扎实就绪，不留半拉子工程，不随意开辟新杂项，填满做好现有领域。
3. **彻底扫清任何软弱与推脱**：
   绝不向用户要授权、绝不因为无卡密而罢工、绝不以写了详细文档冒充完成。
4. **换机与换模型零改动**：
   一次适配全盘通用，未来在实际开发与作战中，绝不再需要去改动中枢的任何核心代码！
