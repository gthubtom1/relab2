## 这是什么

装进 AI 智能体的工程纪律。`04-console` 是页面，`03-bundle` 是打包器，
`02-hubcore` 是规则本体，`ctxiso` 是按意图取资料的任务包。

**没有第三种东西。** 装出来的 91 个文件搜不到任何源仓路径、盘符、远端地址——
这道检查在 `pack.py` 里，不通过就拒绝出包。

## 规则的唯一形态

**规则全文内联进宿主入口文件**（2026-09-28 起）。没有「短句 + 指针」那一层了。

改规则就改 **`02-hubcore/AGENTS.md`**，然后：

```bash
cd 03-bundle && python pack.py          # 重打产物（内联的是 dist 那份）
cd 04-console && python -B selftest.py  # 重装到本机那家验证
```

**改规则的规矩**：

- `BOTTOM_LINES` 的 12 条短语是**自检判据**，必须逐字对得上 `AGENTS.md` 的真实措辞。
  改了措辞不同步，装包时直接拒绝装（`pack.py` 退出码 1）。
- `MARKER_BUDGET = 32000` 是**拦异常膨胀**的闸，不是设计目标。
  **规则该写多长就多长，不要为了凑这个数删底线。**
- 这个项目**不追求省 token**——主人从没要求过。省字节换来的风险
  （模型不跟着指针跳）已经吃过一次亏，见 `01-design/当前实测基线.md`。

**文档分三类，别混**：

| 类型 | 文件 | 怎么用 |
|---|---|---|
| **现状** | `01-design/当前实测基线.md` | **唯一数字口径**，说"现在是多少"只认它 |
| **规程** | `01-design/底模适配说明书.md`、`AGENTS.md`（本文件） | 照着做 |
| **历史存档** | `01-design/历史-*.md`、`TASKBOARD.md`、`00-ANALYSIS/`、各 `RESULT.md` | **只读，不照着改代码**。里面的数字基本都是旧结构的（三层常驻 / 标记块 1,000 B / `CORE.md` 2,988 B） |

`TASKBOARD.md` 和各 `RESULT.md` 顶部都有过时警告，但**警告可能被跳过**——
判断一份文档能不能照着做，看它是不是带日期戳的快照。

## 验收闸（退出码 0 才算过）

```bash
cd 04-console   && python -B selftest.py
cd 03-bundle     && python pack.py
cd 02-hubcore    && python build_hubcore.py --product <项目根> --check
cd 06-verify     && python probe_marker.py
```

页面改动另加 `node --check 04-console/web/app.js`（三元表达式括号写错会直接白屏）。

**别信"看起来对"**：`HTTP 200`、测试绿、文件存在、子代理说通过，都不算证据。
探针没过就是没完成；证不出来说"未验证"，禁说"全测完"。

## 别引入的东西

- 第三方依赖（只用 Python 3.10+ 标准库）
- 联网（中枢自己不联网；客人技能按它自己的规矩办）
- 碰 Skill 目录（不装、不整理、不扫描）
- 源仓绝对路径、盘符、远端地址（会打进包，被自己的检查拦下）
