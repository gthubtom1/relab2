# hubcore · 外置中枢

一套装进 AI 智能体的**工程纪律**：把选好的几段写进那家的入口文件，
让它在开工前先做工程判断、每一步都有物理证据、坏了能原样卸回来。

**纯本机。不联网、不碰 Skill、只用 Python 标准库。**

> **给 AI 的入口：主人在你这加新底模／改规则，先读 [`这里读.md`](这里读.md)。**
> 那里有一张表，说明"主人说哪句话 → 你该读哪个文件"。

---

## 它是什么，不是什么

**是**：一个工作台页面 + 一个打包器 + 一套规则文件。选一家已装的智能体 →
勾几段 → 写进它的入口文件 → 不用了原样摘掉。

**不是**：不是智能体，不是插件市场，不是云端服务，没有任何 AI 供应商接口。

**它只做一件事**：把"这套规矩"装进任何支持入口文件的 AI 客户端——
`.codex` `.claude` `.cursor` `.grok` `.gemini` `.deepseek` `.hermes`
`.pi` `.dsh` `.zcode` `.config/opencode` `.codeium/windsurf` `.aider`，共 13 家。

## 30 秒上手

**Windows**：双击仓根的 **`新中枢工作台.bat`**
（自动找 Python → 起本机服务 → 开浏览器。关掉那个黑窗口 = 关掉工作台）

**命令行**：

```bash
cd 04-console
python run.py            # 起服务并打开浏览器
python run.py --no-open  # 只起服务
python run.py --port N   # 指定端口（默认自动挑空闲端口）
```

地址里不带令牌：进页面时服务端下发会话 Cookie（HttpOnly + SameSite=Strict）。

## 装进去的是什么

入口文件里写三段，顺序固定：

```
宿主原文  →  底模块  →  客套指引块  →  中枢标记块（永远最末）
             ↑ 你的心智   ↑ 别人的成品    ↑ 底线，最终裁决
```

| 段 | 是什么 | 能不能换 |
|---|---|---|
| **中枢标记块** | 12 块底线（证据分级 / 点头规则 / 动作绑定 / 保存≠读取 / 危险动作…） | 固定 |
| **底模** | 你自己那套心智和说话方式 | **随时换** |
| **客套指引** | 别人的成品提示词、索引，原样粘 | 随时换 |
| **宿主原文** | 智能体本来的规则 | **一个字不动** |

**标记块写最后是刻意的**——这是当前实现的拼接顺序和一个有利信号。
是否真正生效仍取决于宿主、模型和客户端行为，必须用目标环境做行为验收，不能只靠文件位置推断。

**工作流、门禁、地图、清单一个字都不进入口文件**，它们装在 `hub/` 下按需读。

## 规则怎么进上下文

**规则全文直接内联进智能体的入口文件**，外面套一对定界标记：

```
~/.pi/agent/AGENTS.md   →  当前样本约 23.6 KB，就是中枢规则全文（随宿主路径变化）
```

模型**不读也不会漏**——不需要它顺着指针跳去别的文件。

装进去的 `hub/` 目录里还有 `AGENTS.md` / `CORE.md` 的副本，那是给
`uninstall.py` 核对「这块是不是中枢写的」用的，以及你手动查阅时用。

> **为什么不是"短提示词 + 指针"**
>
> 最早的设计是入口文件里只放 11 句压缩短句（1,353 B），细则推到
> `CORE.md` 和 `AGENTS.md`，靠指针指过去、赌模型会跳。
> 实测的问题是**它可能不跳**——指针那行是裸文件名，在家目录根和
> `hub/` 下都有同名文件，路径有歧义。
>
> 而当初这么设计的理由写的是"省 token"。**省 token 从来不是这个项目的要求**，
> 只要求效果最好。省字节换来的风险是自己造的，所以不省了。

完整数字与复现命令见 [`01-design/当前实测基线.md`](01-design/当前实测基线.md)。

## 卸载

```bash
python <家目录>/hub/uninstall.py --host-home <家目录> --yes
```

装了什么就精确卸什么，**宿主原文逐字节还原**。摘完与备份逐字节相同才还原备份；
不同就只摘块、不覆盖主人后来的修改。

工作台里的「卸回」会摘三段并删除本系统受管的 `hub/` 文件；你后来放进 `hub/`
的未受管文件会保留。「恢复」按保险箱快照全字节还原。两者不是一回事——日常收尾用「卸回」。

## 一键自测

改完代码必跑，退出码 0 才算过：

```bash
cd 04-console   && python -B selftest.py                              # 工作台自测
cd 03-bundle     && python pack.py                                    # 打包 + 禁词 + 卸载器同步
cd 02-hubcore    && python build_hubcore.py --product <项目根> --check # 禁词 / 瘦身比 / 必需件
cd 06-verify     && python probe_marker.py                            # 标记块在 5 个必验宿主
```

页面改动另加一道：`node --check 04-console/web/app.js`。

## 硬约束

- **不联网**，不引第三方依赖，只用 Python 3.10+ 标准库
- 服务只绑 `127.0.0.1`，页面完全离线自足
- **不碰 Skill 系统**：不装、不整理、不扫描别人的技能目录
- 装出来的文件里搜不到源仓路径、盘符、远端地址
- 快照可能含凭据，落在 `%LOCALAPPDATA%\HubCoreConsole\safebox\`，**不进版本库**
