## 三个必须记住的结论

### 1. 污染不是"存太多"，是"读回来太随便"

自动记录**一件都不用删**——主人原话、账本、改动图、项目记忆、交接纸，该记的都记。
问题从来不在**存不存**，在**记下来的东西什么时候又被读回去**。

### 2. 压缩这一层，旧系统根本没有

`work/v0.1.0/hubdock/` 全目录搜 `summar*` / `compact*` / `trim*` / `distill*` / `forget*`：**0 命中**。
压缩交给宿主智能体自己总结，而宿主总结的是"当时上下文里的一切"——**包括插头、包括那段缺口长文**。
所以那不是压缩，是**历史的二次固化**。

### 3. 删技能库不会崩程序，坏的是文字指向

程序里没有一张"哪个阶段用哪本技能书"的路由表——`hub/.agents/skills/README.md:45` 自己写着「**全靠约定，没有 py 路由表**」。
所以把技能夹整个删掉，程序不会崩；**崩的是那些指向空气的句子**，以及智能体拿着幻觉继续干。

**这直接决定了新系统的做法**：不是"删技能"，而是**先把文字改成指针，再让不读指针也丢不掉底线**。
