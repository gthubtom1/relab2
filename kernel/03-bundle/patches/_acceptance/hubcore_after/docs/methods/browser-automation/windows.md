# 窗口、框、层、挡板

先勾 [catalog.md](catalog.md) D1–D8。

## iframe

- 顶层 locator 看不见框里的控件。用 `frameLocator`，保险点也在框里采。
- 嵌套框一层一层进。跨域框有的根本进不去：停，不要像素点。
- 父页透明遮罩盖住框：框内自测可点，实际点到遮罩。失败看谁在最上面。
- 框 detach（刷新、登录跳转）后旧 frameLocator 作废，重新认。

## Shadow

- 开放 Shadow：role/text 一般能穿，不要手写 `shadowRoot`。
- 封闭 Shadow（支付组件、部分播放器）：穿不进去。停或走官方 SDK。禁止像素点。
- iframe + 封闭 Shadow 套在一起：先框后组件。

## 新标签 / popup

- **先** `waitForEvent('popup')` 或 `waitForEvent('page')` 再点。后听会丢。
- 之后操作必须在新 page 上。旧页继续点是最常见串台。
- `window.open` 若发生在 click 之后的 `await`/定时器里，会被弹窗拦截。必须跟用户手势同一拍。
- COOP/COEP 下 `opener` 可能是 null，关弹窗后不要假设还能指挥父页。两边都重新认状态。
- 关掉新页后回到哪一张，合同写清。
- 多标签：锁同一个账号，不要并行点同一站。页上的外链若超出域名白名单，不要点。

## 原生 dialog

- **先**听 `dialog`。`alert`/`confirm`/`prompt`/`beforeunload`。
- 离开页默认 dismiss。业务确认才 accept。prompt 回填的值写进合同。
- 没监听 = 整段卡住或自动乱点。

## 页内层

- HTML `dialog`、抽屉、全屏层：保险点带「层内标题」。同名「确定」先缩到这一层。
- 多层叠：认最深一层。关掉一层后重新快照，不要连点两次确定。
- `addLocatorHandler` 只绑合同白名单挡板（订阅、cookie）。不要用它关业务窗、支付窗、验证码。

## 挡板

| 类型| 处理|
|---|---|
| cookie / 订阅 / 「我知道了」| 白名单，关掉|
| 权限气泡 通知/位置/相机/剪贴板| 合同允许才 grant；否则停给人|
| 登录墙| 进登录桶，不是挡板|
| 验证码| 停，禁止破解|
| 支付/危险确认| 禁点，除非合同写死允许|

## Canvas / 地图 / 无 DOM

没有稳定无障碍节点就不要做关键点击。截图像素会随缩放、字号、多一列而偏。这类标「做不到」比假成功干净。
