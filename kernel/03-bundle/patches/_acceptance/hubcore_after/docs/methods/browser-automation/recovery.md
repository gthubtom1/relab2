# 卡住与恢复

任何程序共用。上传只是其中一种。

## 先分桶，再动手

现场至少：URL、可见原文、保险点命中几个、指纹冻了没、截图。没有新证据禁止改代码。

| 桶| 页上信号| 做|
|---|---|---|
| 材料拒绝| 格式、超限、无法解析、校验红字针对这一条| 换下一条|
| 页脏 / 回执丢| 进度冻、下一步点不了、上一单还在、层关不掉| 回已知空态，同一条最多 2 次|
| 还在动| 百分比、字节、条数、进度条在变| 等|
| 挡板| cookie、订阅、我知道了| 只关白名单|
| 点了没反应| 按钮看得见，next 保险点不来| 等 hydration/选项；不要死点|
| 登录 / 验证码 / 风控| 跳登录、验证码、异常| 停。连已登录窗。禁止破解|
| 权限 / 扫码 / 短信| 系统气泡、二维码| 停给人|
| 空壳| 没数据但也不像空态原文| 先当被挡，不要写成零条成功|
| 限流| 429、太频繁| 环境问题，退避|
| 下载失败| 文件 0 字节或 HTML| 不要当导出成功|
| UNKNOWN| 点过但对不上唯一对象| 不计数、不删源|

## 换策略，不加重试次数

1. 关白名单挡板  
2. 新快照认状态（不要靠记忆）  
3. 滚进视口，换定位（role → 精确可见文本 → 测试 id）  
4. 回已知空态再走同一条（有限次）  
5. 换下一条或停给人  

禁止：同一坐标连点三次；加长 sleep；retries=5；页内「再添加/更换」当救命；把刷新失败标成材料坏。

## 幂等与账本

提交、支付、发布、删除：**默认只发一次**。回执不明进 UNKNOWN，禁止再点同一提交键。

每条对象写账本：id、做到哪一步、最后保险点结果、是否已提交。崩溃后只恢复「未提交」的。已提交的去平台核对唯一 ID，不要重放。

合同写死：最大步数、墙钟。超了停，不当卡住去刷新空转。

## 乐观 UI

next 多数刚过就立刻做下一步，会被服务器打回。先走 [proof.md](proof.md) 的耐久再采。打回后当页脏，回空态，不要当材料拒绝。

## 空态

每条任务开始必须看到合同空态（投放原文 / 空列表原文 / 登录后的干净工作台），且否决项一个都没有。做不到就刷新；刷新后仍不是，停。不要在半成品上继续。

## 刷新

刷新比页内「重来」干净的情况：上传向导、脏表单、关不掉的层。刷新本身 `ERR_ABORTED` / frame detached 先当噪声，再看空态在不在。回不到空态 = 环境问题，保留对象稍后试。

## flake 四桶（对照）

时机赛跑、上一条状态泄漏、同名定位歧义、登录/配置接线。对号入座后再改合同，不要先改超时。
