## 认步规则

1. 先匹配硬状态和否决（登录、明确拒绝、权限窗、近义禁词）。否决一票，不算 4 里中 2。
2. 再匹配最深的打开层（编辑层 > 选择层 > 表单 > 列表）。
3. 没投过文件/没开过任务却已有对象 → 脏页，回空态，不要再添加。
4. 同文案多按钮：父级 + 可见 + 可点 + 精确文本。横竖版/实验组键名不同则并列。
5. iframe 内的保险点在框内采。popup/dialog/download/filechooser/page **先听再点**。
6. toast 可进拒绝，不要进「做成了」。
7. 抽取对唯一 ID；下载对磁盘文件头；登录对账号专属标记。

## 恢复

1. 只关新手挡板，不关本步业务窗，不点取消业务。
2. 材料拒绝 → 换下一条。
3. 页脏/回执丢 → 回到空态，同一对象最多 2 次。
4. 回不到空态 → 保留对象，当环境问题。
5. 登录/验证码/扫码/结果不明 → 停。

细节见 [recovery.md](recovery.md)。
