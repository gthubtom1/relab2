# 登录与会话

先勾 [catalog.md](catalog.md) E1–E6、I3、I4、I8。

## 原则

优先 **CDP 连主人已登录的窗口**。不要为了方便另开一套账密自动化。会话文件含 token，进 `.gitignore`，不要写进技能仓和产品仓。

## 账密登录（合同允许才做）

1. 等登录表单真的可填（SPA 延迟）。
2. 填用户名/密码（密码不入日志）。
3. 点登录 **之前** 想好会不会出第二页：验证码、扫码、短信、TOTP、OAuth 弹窗。
4. 做成：登录表单卸掉 **且** 账号专属标记（昵称/ID） **且** 受保护内容。到达 `/dashboard` 不够。

## 必须停给人

- 图形验证码、滑块、点选图片
- 短信 / 邮箱码 / TOTP
- 二维码 / App 确认 / 微信扫码
- WebAuthn / passkey / 安全密钥
- 邮件魔法链接（去邮箱点开）
- 风控「异常登录」
- 未授权的别人的号
- 支付卡号 / CVV（PCI：停在支付前）

禁止：打码平台、滑块轨迹、绕过风控、撞库。停，把窗口留给主人。

## OAuth / SSO

- 常是 **popup** 或整页跳转。先听 popup / 等 URL 域名变成认证方。
- 认证方页面可能有自己的 iframe。回跳后要等本站受保护内容，不要在认证域上继续跑本站选择器。
- 有的站用 `window.opener` 回传，关掉弹窗时机写进合同。

## 会话恢复

| 做法| 何时|
|---|---|
| CDP attach| 主人已经在用的窗口|
| `storageState` 读写| 明确授权的保活；文件加密或本机权限收紧|
| Cookie / localStorage 单项| 只当站点确实把登录放这里|
| IndexedDB / 其它源| 探查勾「会话在哪」；只导出当前源会丢 SSO|
| 每次重新登录| 容易限流，避免|

storageState 过期 = 突然跳登录，像元素消失。先认登录硬状态，不要当选择器坏了。SSO 要覆盖**访问过的所有源**的 Cookie，不要只存业务域。HttpOnly Cookie 不能从 `page.evaluate` 读，别用这段当「没登录」。

Google One Tap / FedCM 是独立 UI，不是普通表单。合同没写就停给人。

## 掉登录

每拍先匹配登录硬状态。中途掉了：停或走合同里的「重新附着」，不要把后续步骤当材料失败。

## 多账号

一个 BrowserContext 一个号。禁止共享 context。并行跑同一号会互相踢。窗口标题/端口写进合同，attach 时核对这些，不要连错档。

## HTTP 认证 / 客户端证书

Basic/NLTM/证书用 context 选项，不是页上填表。合同单独写。证书和密码不进仓库。
