#### 整块字节数随宿主家目录路径长度变——但**闸门量的是正文，不量整块**

**先更正我自己**：我上一轮担心"1,200 在长路径上会被突破"——**这个担心是错的，实测后撤回。**

`pack.py:218` / `install.py:219` 量的 `body_bytes` 是**去掉标记行和指针行之后的正文**，
也就是 **11 块底线**那部分，**与宿主路径无关**：

| 量 | 字节 |
|---|---|
| **闸门量的正文 `body_bytes`** | **975 B**（`BOTTOM_LINES` = 11 行） |
| 预算 `MARKER_BUDGET` | **1,200 B** → **正文余量 225 B** |

**结论分两句**：

1. **闸门是对的**——它管的是真正该守住的东西（底线正文），**路径展开不进闸门**。
   这正是"预算要定在稳定的那一份上"的正确做法，我上一轮建议的方案 ② 已经被实现了。
2. **但"整块"这个数仍然没有任何上限**。它随宿主家目录路径长度浮动

   **所以"1,200"这个数对整块不成立**，文档里所有"常驻 1,200 B"的说法
   **严格讲指的是正文预算，不是整块**。

def insert_marker(text: str, host_home="") -> str:
    """先摘旧块再插新块，重复安装幂等。宿主原文一个字不动。"""
    stripped, _ = strip_marker(text)
    stripped = stripped.lstrip("\r\n")
    block = marker_block(host_home)
    return block if not stripped else block + "\n" + stripped
