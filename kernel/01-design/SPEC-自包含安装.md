# 规格书：自包含中枢（hubcore）安装形态

> 这份是所有子代理的共同契约。**任何人不得改动别人的文件分区。**
> 唯一真源。改这里要先问主人。

## 0. 不可协商的硬约束

1. **零外部路径。** 装完之后，系统运行期间读写的每一个文件都在**宿主自己的家目录**里。
   任何字符串、任何配置、任何生成物，都不许出现 `D:\临时项目`、`work/context-isolation`、
   `hub-dock` 源仓路径、或任何本机绝对路径。
2. **不改旧系统。** 旧中枢（`hub/`、`work/v0.1.0/hubdock/`、`.hub/`、根目录文档）一个字节都不动。
   新系统只**读**它们来取材，然后写进自己的目录。
3. **可一键卸载。** 装了什么就精确卸什么，不留残余，不碰主人原有文件。
4. **不联网。** 不拉取、不推送、不发布。新系统没有任何远端地址。
5. **不碰 Skill 系统。** 不装、不扫、不路由、不索引任何 skills 目录。
6. **旧系统必须继续可用。** 新旧可以并存，不冲突。

## 1. 安装后的目录形态

装进宿主家目录（例：`C:/Users/<主人>/.codex/`）之后：

```
<宿主家目录>/
├── AGENTS.md                       ← 宿主原有文件，只在标记块内被改
└── hub/                            ← 本系统全部家当，自包含
    ├── CORE.md                     ← 常驻核心（约 2.5–3 KB）
    ├── AGENTS.md                   ← 全量规则（按需读）
    ├── workflows/  6 套工作流
    ├── methods/    按需方法书 + INVARIANTS
    ├── docs/       门禁、记忆、交接、口径
    ├── templates/  6 套阶段表 + 门禁样例
    ├── tools/      state.py 等运行核（从旧中枢原样搬）
    ├── ctxiso/     上下文隔离侧车
    ├── install-manifest.json      ← 装了什么、逐文件 sha、怎么卸
    ├── uninstall.py               ← 一键卸载
    └── .backups/                   ← 宿主原文件的备份
```

`<宿主家目录>/AGENTS.md` 里的标记块内容**只有这几行**（其余全部靠指针）：

```
# >>> hubcore hub >>>
本机中枢：规则在 <宿主家目录>/hub/AGENTS.md，核心在 hub/CORE.md，工具在 hub/tools/。
掌舵不施工。先推演使用 → 找最值得先查的未知 → 据事实改安排 → 走完一段再扩展。
文字报告不是物理证据；探针没过就是没完成。点头只认主人本人。
保存 ≠ 读取：历史资料默认不进上下文。开工先 hub/tools/../ctxiso 取任务包，要读正文必须带意图。
选好产品线后读 hub/workflows/<产品线>.md。本系统不联网、不碰 Skill。
# <<< hubcore hub <<<
```

块内**不许出现任何技能名、任何开发目录路径、任何远端地址**。

## 3. 装 / 卸 的语义

**装**
1. 宿主必须在**空闲**状态；运行中的宿主一律不写。
2. 先把宿主 `AGENTS.md` 整份备份到 `hub/.backups/AGENTS.md.<时间戳>`。
3. 写 `hub/` 整棵树（先写临时目录，再原子改名，避免半装）。
4. 在宿主 `AGENTS.md` **最末**插入标记块（顺序：宿主原文 / 底模块 / 指引块 / 标记块）；宿主原文一个字不动。
   控制台的「宿主原文」开关**默认开着**＝覆盖模式：宿主原文整段丢弃，只在入口文件里留我们写的几段。
   丢的那份原字节仍在 `hub/.backups/` 里存着（第 2 步就拍了），重复覆盖安装时接着上一棵树那份，
   所以卸回永远还原的是**真原文**，不是上一轮的中枢文本。
5. 写 `install-manifest.json`：里面记 `entry_file.marker_body_sha256`（标记块里那一截规则正文的指纹）。
   装了**中枢内核卡**时块里的正文是那张卡，不是包里的 `AGENTS.md`——卸回/重装靠这份指纹认块，
   否则自己写的块会认不出来（重装叠块、卸回摘不掉）。
6. 立刻**自检**：随机抽 3 个文件对 sha；跑一次 `ctxiso status`；跑一次 `state.py --help`。
   任一失败 → 整体回滚，不留半装状态。

**卸**
1. 读 `install-manifest.json`。
2. 宿主 `AGENTS.md` 只摘掉标记块（认块判据：清单里的正文指纹，或包含包内规则全文）；
   摘完若与备份逐字节相同，说明没被别人改过，直接还原备份。
   若已被别人改过，**只摘块，不覆盖**主人后来的修改。
   覆盖模式（清单里的 `origin_dropped`）：还原 = 备份里的原文 + 摘块后剩下的那部分（主人装完后自己加的）。
3. 删掉 `hub/` 整棵树。
4. 打印一份人能看的卸干净清单。

## 4. 验收（不是"看起来对"）

- 装完后，**把源仓整个改名或移走**，系统仍能正常工作（这条是自包含的硬证明）。
- 装完后 `Select-String` 全部装出来的文件，搜不到源仓路径、`hub-dock`、`github.com`。
- 卸载后，宿主 `AGENTS.md` 与装之前逐字节相同。
- 常驻进上下文的内容 ≤ 3 KB。
