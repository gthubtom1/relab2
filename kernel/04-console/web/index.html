底模（心智） 关着

你自己写的一套心智，装进去在第 2 段（宿主原文之后）。同一时刻只用一张，点「用这张」换。只读 cards/base/ 子夹——不想用的卡挪出这个子夹就等于停用，卡不丢，挪回来就能用。

客套指引（成品文本） 关着

别人的成品提示词，原样粘在最后，卸的时候按定界整块摘掉。同一时刻只用一张。只读 cards/guest/ 子夹。

写法 直写：整份替换

开着＝直写：把选中的几层（底模 → 指引 → 中枢）按顺序拼成一份， 整份替换这一家的系统规则文件；原来那份进保险箱，随时能退。不走打包器。 关掉＝完整安装：叫打包器，另外把 hub/ 那棵树（工具、工作流、文档）也写进去， 原文保留在最前面。
