# 交付说明 · 外置中枢 · 工作台

日期：2026-09-28　　产品目录：`work\context-isolation\04-console`（源码）+ `03-bundle`（打包器）

## 一、这是什么

一个只绑本机的工作台：卡片按层分家（cards/hub、cards/base、cards/guest 三个子夹，池子外一律不读＝停车位）
→ 选一家已装的 AI 智能体 → 勾三段（中枢标记块 / 底模卡 / 客套指引卡）
→ 点「载入」把三段写进那家的入口文件；「宿主原文」那颗开关默认开着＝覆盖（原字节进备份，
点「卸回」时按备份合并还原，逐字节回到装之前） → 不用了点「卸回」原样摘掉。

**没有 AI 供应商、模型接口、授权、收费、订单、联网**——那套是你自己的，不进这个产品。
控制台只写本机文件，全程环回，标准库，不装任何第三方依赖。

## 二、怎么开

双击 `04-console\start-console.bat`。自动找 Python、起本机服务、开浏览器。
地址只有端口，没有令牌后缀。关掉那个黑窗口 = 关掉控制台。

命令行也行：`python run.py` / `--no-open` / `--port N`。

## 三、这一轮修了什么（都是真洞，不是润色）

### 会毁主人数据的（阻断级）

1. **CRLF 文件上「装得上、卸不掉」**：主人用任何 Windows 编辑器把入口文件存成 CRLF 之后，
   卸载器的行尾锚点 `[ \t]*$` 匹配不上那个 `\r`，于是**中枢的块原封不动留在入口文件里**，
   而打包器回的是"卸干净了"。智能体会继续读那套已经卸掉的规则。
   修法：装与卸两边的定界行正则都容忍一个行尾 `\r`。回归判据在 `selftest.py` 验收 9。
2. **「重新载入」在刷新页面后 = 静默删掉已装的底模和指引**：页面从不从装好的记录里回填
   "现在用的是哪张卡"，你 F5 一下开关就全回默认，按下去打包器把三段先摘干净再只插回勾过的。
   修法：选中一家时从记录回填三段状态；**并且**这次要摘掉哪几段会先弹窗点名，问完才写。
3. **卡片正文里混进一行中枢的定界行**（`# <<< hubcore guest <<<` 这类，成品提示词里很常见）：
   卸回按定界摘块会只截一半，卡片后半截永久留在主人的入口文件里，**被当成他自己的指令读**。
   修法：存卡和装卡时都拒收，并指名是哪一行。
   （这条破了"原样粘、一个字不改"的承诺，我选了诚实那一侧。要放开你说一声。）

### 假完成

4. 页面说"装好了 / 正在用 / 中枢已进"，判据原来是"`hub/` 目录在不在"。现在一律按**入口文件实测**
   （标记块/底模块/指引块逐段在不在、定界成不成对），hub 目录在、入口里没有 = 明确说"hub/ 在，入口里没找到"。
5. **「改」卡片之后**：装的时候记在 `install-manifest.json` 里的卡片正文字节被拿来和现在磁盘上的比，
   不一致就显示「正在用（你改过，没重装）」，三段那一栏也写明"智能体里还是旧的"。
6. 「重扫」以前和「刷新」是同一个函数（点了像有反应，其实什么也没多做）。现在「重扫」真的按入口文件重扫并给报告。
7. 「深扫全盘」点一次之后**每 5 秒全盘扫一遍**直到关页面。改成一次性动作。

### 安全

8. **保险箱搬出产品夹**（这轮最要紧的一件）：快照里存的是宿主配置的全字节副本，
   这台机器上 `settings.json` / `config.toml` 里**确实有 `ANTHROPIC_AUTH_TOKEN` 和
   `experimental_bearer_token`**，而旧过滤只按文件名判"是不是凭据"，那两个文件名一个都没命中。
   保险箱原来躺在一堆 JSON 快照里（`04-console\safebox\`，而这个目录**不在 .gitignore 里**、整个 04-console 未被 git 跟踪。
   现在：快照搬到 `%LOCALAPPDATA%\HubCoreConsole\safebox\`（旧目录已整个搬走，不留拷贝），
   `04-console\.gitignore` 加了 safebox/cards/hostlist/TEMP。
9. 鉴权：删掉"Origin/Referer 里带本机端口就放行"那条（本地程序自己就能填这个头，等于没门），
   改成只认 Cookie 或 `Sec-Fetch-Site: same-origin`（浏览器强制字段，脚本伪不了）；**加了 Host 头白名单**
   （不校验的话，攻击者把域名指到 127.0.0.1 就能在攻击者的源上同源操作控制台）；令牌不再出现在
   `/api/status` 正文和终端日志里。

### 数据完整性

10. 保险箱快照记录这一版是「装前」还是「装后」，**恢复优先挑装前那一版**并在结果里说清是哪一版、
    哪几个文件是你在这之后自己改过的；快照文件名带路径成分的直接跳过；恢复写盘改原子替换。
11. 快照只留最近 3 份（装 20 次不该有 20 份配置全字节躺着）。
12. `with_marker` 必须是布尔值（`bool("false")` 是 True，传字符串会把 12 块底线照写）。
13. 「适用谁」备注里的换行会被拼进卡片正文 → 强制单行。
14. 「看卡」回填不再用 `split("\n\n")`（手写的卡少一个空行就会吃掉第一段正文）。
15. 一个非 UTF-8 的 `.md` 不再让整页瘫掉；请求体超限不再把连接搞错位。

### 控件不许是假的

16. 「别列这家」以前对内置名单和手加的家**点了没反应**（它只挡扫出来的那几家），而且**不可撤销**。
    现在对所有家都真生效，扫描报告里每一条都带一个「恢复显示」按钮；手加的那家改用「从名单拿掉」。
17. 开开关不再"自动挑最近一张"闷头写进去；选卡不再顺手打开那一段（只有那颗开关能开关）。
