### 2. 工具定位（唯一入口：TOOLS.md）

**严禁凭记忆、凭目录名、凭经验猜工具路径。** 完整探测是**四级递进，命中即停**：
`env` → `PATH` → `D:\Tools\_map.json` 别名 → 工具根递归。

```powershell
# 最省事：直接用探测层
. C:\relab2\skillpack\skills\scripts\lib\Bootstrap.ps1
$r = Resolve-ReverseToolSpec -Name 'idat'
$r.Available   $r.Command    $r.Via    # Via: env / PATH / map / scan

# 只问「装没装」：
(Get-Command <工具id> -ErrorAction SilentlyContinue).Source
```

**为什么不能只靠 `Get-Command`**：商业工具在 `D:\Tools\<分类>\<工具名>\` 里，
目录名不等于工具名（`IDA_Pro_v8.3_Portable\` 里才是 `ida`），且不在 PATH 上。
探测不出来、只能声明的关系（目录名映射 / 同名多份 / **要排除的陷阱**）写在
`D:\Tools\_map.json`。**陷阱很要紧**：IDA 自带的裸 Python 没有 pip 包，误命中它，
脚本就跑在没有依赖的解释器上。

**四条硬规矩：**

1. **没查到就是没装。** 不许猜、不许拼目录、不许拿「上次是有的」当依据。
2. **不许把探测到的路径写回任何文档。** 路径只活在当次会话里 —— 换台电脑它就不成立。
3. **装完必须复验。** 装完不跑探测等于没装。
4. **`Via=scan` 的要留意身份。** 靠文件名扫出来的、版本资源被剥的 exe 只能算「疑似可用」，
   需实跑一次版本输出确认后才能依赖。

工具**约定**装在 `D:\Tools\<分类>\<工具名>\`。但这是约定不是保证：`winget` 装的进
`C:\Program Files\`，pip 的进用户 `Scripts\`，SDK 的进 `%LOCALAPPDATA\`。**探测对所有工具都必做。**

### 4. 命令执行纪律（固定规则，全场景，含非逆向的全栈工作）
1. **每条 shell 必须带 timeout**：探查 30s / 分析 120s / 构建 600s。宁可短超时后重试，不可长超时后干等。
2. **GUI / 交互式二进制禁入 bash**：这类程序弹窗等输入、零 stdout、进程永不退出，同步等它 = 模型全程不运行且不自愈。
   已确认的替换关系（路径按 §2 探测）：`die.exe` → `diec.exe`（`-d -e -j <file>`）；`Wireshark.exe` → `tshark`；
   `ida.exe`/`ida64.exe` → `idat.exe`（headless）或 `analyzeHeadless`；`x64dbg.exe` → 控制台 headless 版；
   `dnSpy.exe` → `dnSpy.Console.exe`；radare2 的 `-g` 属 GUI，禁用。
   **无 CLI 孪生的（PE-bear、Scylla、010 Editor、JEB）只能人工在桌面侧操作，agent 不得拉起。**
3. **一条命令只做一件事**：链式 `&&`/`;`/`|` 不超过 8 段，不跨主机、不跨路径体系。Git-Bash 下 `/tmp` 实为 `C:\tmp`，两端路径分两次调用。
4. **长操作后台 + 轮询**，禁止同步阻塞：批量传输、首次拉包、大构建、长时间任务一律后台起进程再轮询产物。
5. **快慢命令不得同批并行**：一条无界命令会扣住整轮并行调用中已完成的兄弟结果。
6. **网络类命令必带超时**：`ssh` 带 `-o ConnectTimeout=15`、`curl` 带 `--max-time`、`scp` 带 `-n`；先用一条 `echo ok` 单验连通。
7. **动态调试在本机进行**：调试器、内存注入、驱动加载、未受控样本都在本机跑；调试器优先用控制台版；确需 GUI 观察才起在交互式桌面会话里，不要经管道/服务方式拉起。

### 5. 卡死识别与自检（固定判据）
- **判据**：终端计时器持续上涨 + token 计数静止 = 卡在命令层，不是在推理层。命令阻塞期间模型不在运行、没有任何代码在跑，因此**模型不可能自己发现命令卡住**。
- **处置**：Ctrl-C 中断并改路线。此类中断让回合以 error 终止，**不会自愈**，必须由用户发「继续」恢复。
- **物理兜底**：本机装有 `~/.pi/agent/extensions/cmd-guard.ts`，对 bash 调用自动补 timeout、物理拦截 GUI 二进制，**不依赖模型是否读到本卡**。`/stall` 查当前命令与疑似卡死记录。
