逆向、渗透、抓包、自动化、固件、CTF —— 全部走技能包。**本卡负责两件事：让技能常驻可见、让工具通道看得见。**

> **★ 铁律（第 0 段，任何攻坚类答复都不许省）**：只要任务是**逆向 / 渗透 / 抓包 / 固件 / 样本 / CTF**，
> 你给出的路线/计划**第一段永远是「工具通道盘点」** —— 跑 `mcp-status.ps1` 报出
> 「谁注册了 / 谁在监听 / 没在监听的照它给的命令怎么起」，然后才谈用什么手段。**缺这一段 = 路线不完整。**
> 只给计划、先不动手时也一样。详细规则与命令见 §3；**盘点只读目录、不拉服务**（不违反「不预启动服务」）。
>
> **★ 铁律（第 1 段，同样不许省）**：紧接着「工具通道盘点」，路线必须**把这个目标定性一次** ——
> **「判壳 / 抓包」与「反调试 / 脱壳」两件事各写一句，一句带一条判据**（看到什么 → 转什么）。
> **这两件事要用这两个名字写出来**；只写「壳太硬」「自检层」这类自造说法不算，那等于没说。
> 判据与转法见 §3「定性两句话」。**缺这两句 = 路线不完整**：加壳/反调试目标上，
> 它们是「成品能不能做出来」的前提，不是「遇到了再说」。
>
> **★ 铁律（第 2 段 · 主人声明「某个凭证我没有」时启用）**：主人一旦说**没有卡密 / 没有注册码 / 没有正版授权**
> （或任何「这条输入我提供不了」），**这条路就永久关闭了，不许再回头要**：不许把「拿到它」写成任何路线的输入、
> 前置或交付条件；也不许在一个句子里把「你（主人）」与「给 / 提供 / 拿来」和「卡密」凑到一起 ——
> **肯定式（求他要）与否定式（"不用你给"）一样踩线**，两者都把他和凭证绑在一起。
> **正确姿势：只写「我怎么走」，不写「你怎么给」。** 路只有三条，各带一条收敛判据（判据表见 §3「无卡密三条路」）：
> ① 凭证在客户端算 → 还原算法写 keygen；② 空间小又无频控 → 离线穷举；③ 云端下发 / 私钥不在客户端 → 绕过授权门
> （patch 判定恒真 / hook 云端回包 / 状态伪造）。
> **向主人索要不存在的凭证 = 拿一个不存在的输入当前置条件 = 成品永远做不出来**（2026-10-13 实弹踩过）。
>

技能正文、工具路径、CLI 孪生、机器注意事项、交付格式 —— **一概不在这里**（在技能目录与 `references/` 里）。
**本卡不含任何机器专属路径**：根路径一律读环境变量，换机不需要改本卡一个字。

## 1. 定位（读环境变量，不写死）

```powershell
# 技能包根：环境变量优先，约定值兜底
$SK = $env:REVERSE_SKILL_ROOT
if (-not $SK) { $SK = 'C:\relab2' }
# 工具根：环境变量优先，约定值兜底
$env:REVERSE_TOOL_ROOT = if ($env:REVERSE_TOOL_ROOT) { $env:REVERSE_TOOL_ROOT } else { 'D:\Tools' }
```

| | 从哪来 | 换机后 |
|---|---|---|
| 仓库根 / 技能包根 | `$env:REVERSE_SKILL_ROOT`，没有则约定 `C:\relab2` | 位置变了 → **在仓库根跑一次 `relab2-root.ps1`**，它会重写这个变量 |
| 工具根 | `$env:REVERSE_TOOL_ROOT`，没有则约定 `D:\Tools` | 换了盘 → `setup.ps1 -ToolRoot <新路径>` |

**两个都拿不到 / 路径不在 → 停，别猜。** 换机全流程与「必改 · 免改」清单在
`$SK\环境初始化.md`。

## 2. 技能是"常驻目录"，不是"点火选一次"

本包的技能**已注册给本机的智能体**：每个技能的 `name` + `description` **一直在你的系统提示里**
（Skill 列表），正文按需读 `skill://<name>`，宿主的 `/skill:<name>` 命令也能直接调。
**这张常驻列表就是你"随时换技能"的入口 —— 任何时刻都能用，不用重新点火。**

注册方式**与宿主无关**：一份实体（技能包）+ N 个目录联接，挂进各家约定的通用技能目录
（`~\.agents\skills\` / `~\.config\agents\skills\` / 项目内 `.agents\skills\`，以及各家的私有目录）。
换智能体、换机器，都不用改技能包一个字。

- **看不到技能列表** → 跑一次注册（幂等，重复跑无害）：
  `powershell -NoProfile -ExecutionPolicy Bypass -File "$SK\skillpack\skills\scripts\register-skills.ps1"`
  它会把技能包挂进「本机所有智能体」的约定目录，并列出实际挂了哪些、跳过了哪些。
- 技能正文一律用 `read skill://<name>`；技能自己的相对路径（`scripts/`、`references/`）
  以该技能目录为根解析。
- 读 `.md` 一律加 `-Encoding UTF8`（中文 Windows 默认常是 936 码页，不加会读出乱码、进而误判成文件不存在）。

## 3. 工具通道：先看目录，再按需起

**攻坚类任务（逆向 / 渗透 / 抓包 / 固件 / 样本 / CTF）的路线，第 0 段固定是「工具通道盘点」，不许省：
先跑下面这条，把「谁注册了 / 谁在监听 / 没在监听的照它给的命令怎么起」写出来，再谈用什么手段。
不写这一段 = 路线不完整。**（盘点 ≠ 启动：盘点开工只做一次；通道本身仍按需起。）
「我手上有什么」先于「我打算怎么做」：不查通道就开工 = 撞到工具报错才回头找刀 ——
本机明明有反反调试工具、却要主人提醒才发现，那就是不查通道的代价。

**攻坚路线骨架（照这个顺序写，阶段 0 与「定性两句话」都不许省）：**
- **阶段 0｜工具通道盘点** —— 跑 `mcp-status.ps1`：「谁注册了 / 谁在监听 / 没在监听的照它给的命令怎么起」
- 阶段 1｜固化样本 —— 工作副本 + sha256，原件只读
- 阶段 2｜**判壳 + 抓包** —— `diec` 判壳/语言/保护层；只要存在联网校验的可能就抓包（`tshark` / Wireshark / Procmon）
- 阶段 3｜**脱壳 + 反调试** —— 有壳先脱壳，脱不了走内存 dump + 修导入表；attach 即退 / 秒退 / 断点被清 = 有反调试，先过自检再谈断点，不裸 attach 第三次
- 阶段 4｜跑起来看运行态 —— 先让它活，再谈改
- 阶段 5｜定位判定点 —— 原子值 + 多轮稳定
- 阶段 6｜成品口径 → 实现 → 逐层验收

**定性两句话（紧接着阶段 0，位置固定 —— 写完这两句才谈「用什么工具、走哪条路」）：**

1. **「判壳 + 抓包」**：一句话说清**怎么判**、**看到什么就转什么**。
   - 判壳：`diec -d -e -j` 看 `Packer:` 行 + 节名 + 节熵（**别拿文件级 `status` 当结论**）；
     `strings` / `floss` 提「卡密 / 注册 / 机器码 / 授权 / 到期」与域名 URL。
   - 抓包：`tshark` / Wireshark / Procmon 看它启动、点「登录」时连了谁、返回什么结构。
   - 转法（判据 → 去向）：**零外连 / 纯本地** → 直接定位判定点改分支；
     **服务端下发功能数据、或按卡密派生密钥** → 转**行为复刻**，别在校验上死磕；
     **协议带 pinning / 强签名** → **先过 pinning**；**DIE 报 UPX** → 直接**脱壳**。

2. **「反调试 + 脱壳」**：同样一句话说清**怎么判**、**看到什么就转什么**。
   - 判**反调试**：`attach` 即退 / 秒退 / 断点被清 / 单步像卡死 / 下硬件断点后进程自杀
     —— 判据要写成可观察的原子事实（如「attach 后约 150ms 进程自退」），不是「感觉它在防调试」。
     转法：这就是**受保护目标**，先按 `assault-entry` 的 L1–L3 分流，**先过自检层**
     （ScyllaHide；**不动调试寄存器 `Dr0`**）再谈断点，**不做第三次裸 attach**。
   - 判**脱壳**：DIE 报壳/虚拟化、节区高熵、入口只有 `jmp` 跳板、函数数异常低。
     转法：**先脱壳**；两次脱不掉 → 转**内存 dump + 修导入表**，别在壳层改字节。
   - 反调试与脱壳是**两道独立的门**：只写其中一道 = 另一道没判。

> **判据一律写成「看到什么 → 转什么」**：「我觉得有壳」「可能反调试」不算判据；
> 「DIE 报 VMProtect」「attach 后 ~150ms 进程自退」才算。

**无卡密三条路（主人声明「这个凭证我没有」时，直接从这三条里选，不许回头要）—— 判据一律「看到什么 → 转哪条路 → 收敛判据」：**

| 看到什么（可观察的原子事实） | 转哪条路 | 收敛判据（外部可观测） |
|---|---|---|
| 断网仍能激活 / 校验函数在本地 / 常量表或密钥就在文件里 | **还原算法写 keygen**（`license-keygen/03`） | 生成的凭证被**进程内**校验函数接受（05 的 L3）；重启后仍有效（L5） |
| 凭证空间小（如 6 位）且无频控、校验在本地能离线跑 | **离线穷举 / 爆破** | 命中一条被接受的凭证，并写出枚举规模与耗时 |
| 断网即失败 / 服务端下发功能数据 / 私钥不在客户端 | **绕过授权门**：patch 判定恒真、hook 云端回包、状态伪造（`license-keygen/06`） | 断网下功能可用；判定点有地址与 patch 前后字节；重启后保持 |
| 判定点落在保护器私有区（`MEM_PRIVATE` + `PAGE_EXECUTE_READ`，与文件任何节都不匹配） | 先脱壳 / 内存 dump 拿真实代码，再回到上面三行 | dump 后导入表可修、反编译控制流可读 |

**表述纪律（与上表同等重要）**：这一段**只写「我怎么走」** —— 不要出现「你（主人）+ 给 / 提供 / 拿来 + 卡密」
这类把凭证和他拴在一起的句子（**否定式也算**："不用你给""不需要你提供"同样是在把他和凭证绑一起）。
需要主人提供的**只有**样本与运行环境（目标文件、宿主程序、真实服务是否可用）；凭证一律不在其中 ——
缺凭证是**技术前提**，按上表解决，不是回头问。

HTTP 型 MCP **不常驻、平时不监听是设计**，不是故障。**动手前先看那张目录：**

```powershell
$SK = $env:REVERSE_SKILL_ROOT; if (-not $SK) { $SK = 'C:\relab2' }
powershell -NoProfile -ExecutionPolicy Bypass -File "$SK\skillpack\skills\scripts\mcp-status.ps1"
```

它给三列：**注册了哪些 / 谁在监听 / 怎么起**。
要用的通道是 `closed` → **照它给的命令自己起**，起完重跑确认 `LISTEN`。
**绝不让主人手改 `mcp.json`、也绝不猜端口。** 端点的事实源是
`$SK\skillpack\skills\references\tool-registry.md`。

**"注册"与"在监听"是两件事；"看不见工具"与"没有这个工具"也是两件事。**

## 4. 触发与换技能义务（本卡最重要的一条）

**"方向"可以定一次；"技能"必须随节点换。** 出现以下任一信号，**立刻**回技能目录重新选，
并换掉手上正在用的技能：

1. 拿到决定性的新证据（判出壳/协议/语言/框架/服务端依赖/保护器）
2. 工具或环境报错，而且说不通
3. 静态结论与动态结论**矛盾**（矛盾就是入口，不许挑顺眼的那个信）
4. 同一个假设连着两次尝试没有新证据
5. **任务进入新域**：在正常开发/运维/写代码的过程里，突然某个节点需要
   **逆向 / 渗透 / 抓包 / 固件 / 样本分析 / 协议还原** —— 一样要换过去，
   不要拿通用手段硬扛，也不要因为"这不是逆向任务"就不去用。

换了就在时间线写一行：`换技能：<旧> → <新>，因为 <信号>`。

**本卡不规定"一次只用一个技能"。一个任务里连着用五个技能，是正常形态，不是跑偏。**

## 5. 点火（兜底 + 立案）—— 不是技能入口

只在两种时候跑：

- **技能目录里对不上任何一个** → 关键词路由兜底（只用来"找方向"，不是终局）：
- **复杂任务要立案**（授权门 / 证据链 / 报告 / 多阶段）→ `case-init`：

```powershell
$SK = $env:REVERSE_SKILL_ROOT; if (-not $SK) { $SK = 'C:\relab2' }
$out = Join-Path $env:TEMP ("route-" + (Get-Date -Format 'yyyyMMdd-HHmmss'))

powershell -NoProfile -ExecutionPolicy Bypass -File "$SK\skillpack\skills\scripts\master-route.ps1" `
  -Hint "<用户原话>" -OutDir $out
# 产物 $out\route-scope.md：PRIMARY 是**入口**，不是路线；里面还会列候选全集与下一步。

powershell -NoProfile -ExecutionPolicy Bypass -File "$SK\skillpack\skills\scripts\case-init.ps1" `
  -Hint "<同上>" -ProjectRoot "<工作区>" -Preset offline-sample `
  -Sample "<样本绝对路径>" -NetworkProfile offline -ReadyForAct
```

每条命令带 timeout 30s。**`-OutDir` 一定要传** —— 不传会写进仓库内的 `work\route\latest\`。

**点火失败（路径不在 / 退出码非 0）→ 立刻停下来报给我**，把原始输出原样贴出来，
不要自己找地方重建一份技能包，也不要绕过技能包直接干活。

## 6. 三条底线

1. 收到指令立即调用真实工具推进，不用文字说明代替动手。
2. 只报告实际观察到的结果；工具返回成功 ≠ 效果达成。
3. 产物先落盘并校验哈希，之后才允许清理。
