# 外置中枢 · 工作台（04-console）

只管一件事：**把选好的几段写进某家智能体的入口文件，不用了能原样卸回。**

没有技能管理、没有副插件卡带、没有模型供应商配置、没有云端。
只用标准库（本机实测 Python 3.14.3 跑通；3.12+ 均可），服务只绑 `127.0.0.1`，页面完全离线自足。

## 界面长什么样

三栏一坞，照旧控制台那套工作台思路：

```
顶栏：打包器就绪 / 已装几家 / 刷新
┌────────────┬──────────────────────────────┬──────────────┐
│ 1 智能体    │ 要写进去的几段（顺序固定）      │ 将写入        │
│  14 家名单  │  底模（心智） [开关] 卡片磁贴   │ 保险箱        │
│  点一家选中 │  客套指引     [开关] 卡片磁贴   │ 结果          │
│            │  宿主原文     [开关] 默认覆盖    │              │
│            │  中枢标记块   [开关] 写在最末   │              │
└────────────┴──────────────────────────────┴──────────────┘
3 写进去：[载入] [卸回]        保险箱：[锁定] [比对] [恢复]
```

**标记块写最末是刻意的**：这是当前实现的拼接顺序和一个有利信号。
是否真正生效仍取决于宿主、模型和客户端行为，必须用目标环境做行为验收。

- **三段都能单独开关**，全部关掉就不写（也不会误写）。开关打开但还没点卡片时，
  只提示你去点「用这张」——不替你挑一张（你没选过的卡被闷头写进去，你不会知道）。
- 卡片是**磁贴**，点一下选中/取消，右上角小「删」删卡；末尾那块虚线的「＋」是新建。
- 中间那段**宿主原文**有一颗开关，**默认开着＝覆盖**：入口文件里原本的文字整段换掉，
  只留我们写的几段。原字节由打包器存进 `hub/.backups/`，重复覆盖装载入时接着上一棵树那份，
  所以「卸回」还原的永远是**真原文**（不是上一轮的中枢文本）。关掉这颗开关＝保留原文，
  照旧跟在我们的几段前面，一个字不动。
- 点「载入」时，**服务端会先把这一家的配置面拍进保险箱**；拍不成本次就不写、不碰它家。
  这一道在服务端，不靠页面把按钮点亮。

## 卡片池：每一层只读自己那一个子夹

```
04-console/cards/
├── hub/       中枢内核卡   ← 中枢那个槽位只读这里
├── base/      底模卡       ← 底模那个槽位只读这里
├── guest/     客套指引卡   ← 客套指引那个槽位只读这里
├── _park/     停车位       ← 一个字都不读（不想用了挪进来，卡不丢）
├── _archive/  历史版本     ← 不读
└── _pending/  预写待测     ← 不读
```

- **挪出子夹 = 停用，挪回来 = 启用**。不想用的卡别删，挪进 `_park/`（或 `cards/` 根目录）
  就行——控制台和打包器都只认那三个子夹。
- 顶栏会报「池子外停用 N 张」，告诉你有多少张没在读。
- 卡头那行 `# kind:` 和子夹对不上**不会被拦**：层只看卡躺在哪个池子里（`server.py` 的 `list_cards` 明写「卡片自己声明什么都不算」），`declared` 恒为空、没有 ⚠、载入照走。卡头只是给人看的备注。
- 散卡不知道往哪放：`python 卡片归位.py`（加 `--dry-run` 只看不动），按卡头把根目录的卡
  塞回对应池子；卡头认不出来的留在原地，只报给你看。

## 跑起来

```
python run.py              起服务并打开浏览器
python run.py --no-open    只起服务
python run.py --port N     指定端口（默认 0 = 自动挑一个空闲端口）
```

启动后终端打两行，第一行就是地址：

```
已启动（只听本机）：http://127.0.0.1:60122
页面地址（直接打开就行，不用加任何后缀）：http://127.0.0.1:60122
```

地址里**不带令牌**：进页面时服务端会下发一个会话 Cookie（HttpOnly + SameSite=Strict），
后面的 `/api/` 靠它过闸。`Ctrl+C` 关掉，端口立刻让出来。

## 双击就开（给主人用的）

双击 `start-console.bat`：自动找 Python → 起服务 → 自动打开浏览器到页面。
不需要手抄令牌，不需要开终端。关掉那个黑窗口 = 关掉控制台。

```
start-console.bat              双击，开页即用
start-console.bat --no-open    只起服务，不弹浏览器
start-console.bat --port N     指定端口（默认 0 = 自动挑空闲端口）
```

找不到 Python 时窗口会明说缺什么，不会一闪而过。

## 两种卡片

都在页面中间的磁贴里，末尾虚线「＋」新建：

- **底模卡**：你自己写的一套心智。装进去在第 2 段（宿主原文之后），上限 40,000 字节。
- **客套指引卡**：别人的成品提示词，原样粘、一个字不改，装进去在第 3 段（末尾、标记块之前），
  卸的时候按定界整块摘掉。

**顺序是刻意选的**：标记块写在**最末**一段，作为当前实现的最后规则信号。
主人换任何底模、任何指引卡后，仍要用目标宿主和模型做行为验收，不能只看文件位置。

卡片只活在 `04-console/cards/`（一个卡一个 `.md`），**永不进包**。
卡片**头是可选的**：`server.py` 的 `_parse_card` 明写「只统计，不判断」——层由卡躺在哪个池子里决定（`base/` 就是底模卡，`guest/` 就是客套卡），卡片自己声明什么都不算。所以 `# base:` / `# kind:` / `# hosts:` 这几行写不写都行，`cards/base/muse-1.3.md` 这类真卡开头就是 `[MODE: LAB-LOCAL · ACTIVE]`，照读不误。**没有格式校验、没有 ⚠、不会拦载入。**
正文上限 40,000 字节（每轮都注入，太大拖上下文；8,000 字节只是适配时的软目标）。

## 一键自测

```
python selftest.py                 用真的 03-bundle 跑（默认；装卸都发生在 TEMP 里）
python selftest.py --bundle fake   用 TEMP 里的接线替身（只证命令接上了，字节语义不算数）
```

装卸都在 `TEMP/` 里发生，真家目录一个字节都不碰，测完把服务进程杀掉。
退出码 0 是全过。验收实录见 `RESULT.md`。

## 页面死了怎么查

「点不动、一家也扫不到」这类故障，九成是脚本加载时就抛错（`$('x')` 拿到 null，
下一行就炸，整段脚本死掉，页面只剩静态骨架——看着像示例）。两道闸门锁住它：

```
python 06-verify/check_page_ids.py             页面 id 与脚本引用逐一对账
python 06-verify/page_walk.py <端口> <令牌>     按浏览器顺序真走一遍每个接口
```

页面自身也兜错：任何未捕获的错都摊到右下「结果」栏，不再静悄悄变死。

## 14 个 `/api/` 端点

`server.py` 实跑路由一共 **14 个 `/api/*` 端点**（下面这张表逐条列全；`grep -o '"/api/[a-z/]*"' server.py | sort -u` 会多出 `/api/` 这个前缀本身，别把它当成第 15 个端点）。漏读一条，客户端就会少做一半的事。

| 接口 | 干什么 |
|---|---|
| `GET /api/hosts` | 扫到的宿主：id、显示名、家目录、入口文件、在不在、装没装、在不在跑、版本与两张卡名 |
| `GET /api/status` | 版本、装了哪些宿主、包位置、令牌、常驻 KB、文件数、卡片表 |
| `GET /api/scan` | 只跑扫描并把报告原样给出（`?deep=1` 带深扫） |
| `GET /api/cards` | 卡片表（id、池子、字节数）。只列 `hub/ base/ guest/` 三个池子 |
| `GET /api/card?id=&kind=` | 单张卡的正文全文（带池子查更准；只在主人点名要时用） |
| `POST /api/cards` | `{"name","hosts","content","kind":"hub|base|guest"}` 存进对应子夹 |
| `POST /api/cards/delete` | `{"id","kind"}` 从对应子夹删卡（已装进宿主的不受影响） |
| `GET /api/safebox?host_id=` | 这家的保险箱清单（每份就是一个 `.bak`） |
| `POST /api/safebox` | `{"host_id","action":"snapshot|verify|restore"}`。`verify` 恒回 `ok:true` + `same` + `diffs`：**有差异不是失败**，页面靠 `diffs` 列清单 |
| `POST /api/hosts/add` | `{"name","home"}` 手加一家扫不到的宿主 |
| `POST /api/hosts/remove` | `{"id"}` 从手加名单里拿掉一家 |
| `POST /api/hosts/ignore` | `{"home"}` 点名以后别再列这家 |
| `POST /api/hosts/unignore` | `{"home"}` 取消忽略 |
| `POST /api/hosts/kill` | `{"id"}` 强制关掉这家正在跑的进程（装之前要先关） |
| `POST /api/load` | `{"host_id", "base_id"?, "guest_id"?, "with_marker"?}`，调打包器装入 |
| `POST /api/unload` | `{"host_id"}`，调打包器卸载 |

> 表里 16 行、端点 14 个：`/api/safebox` 同时有 `GET`（列清单）和 `POST`（三个动作），按**路径**数只算一个；`/api/cards` 也是 `GET`（列表）与 `POST`（存卡）共用同一个路径。其余每条各占一个路径。

**保险箱就一件事**：把宿主入口文件原样存一份，要退的时候原样换回来。

```
%LOCALAPPDATA%\HubCoreConsole\safebox\<宿主 id>\<入口文件名>.<时间戳>.bak
```

- **锁定** = 把当前入口文件逐字节存成一份 `.bak`（不算哈希、不写索引、不碰目录/技能夹）。
- **比对** = 现在这份 vs 最近那份 `.bak`，逐行走一遍，差在哪一行说话。
- **恢复** = 把最近那份 `.bak` 逐字节写回入口文件。**.bak 不消耗**，能反复退。
- 每家最多留 3 份，多了删最老的。要换基准就再按一次「锁定」。
- 载入前会自动拍一份，但**已经有就不覆盖**——主人手里那一版是基准，`载入` 不许把它顶掉。

`with_marker=false` = 不写中枢标记块，只写底模/指引（三段都能单独选）。
`replace_origin=true` = 覆盖模式，宿主原文整段丢弃（原字节进 `hub/.backups/`）。**页面默认送 true**；
API 缺省 false 是给自测和命令行留的保守值。`hub_id` 选中枢内核卡：那张卡的正文就是标记块正文。

`/api/status` 里的 `cards` 只有三个池子里的卡；`cards_parked` 是池子外（根目录 + `_park/`）
停用的张数，只报数，不读内容。`/api/card?id=&kind=` 带池子查卡更准（不带也能按三个池子找）。

`GET /` 是单页，另外只发 `app.js` 和 `style.css` 三个文件。
`app.js` / `style.css` 不含秘密，本机回环直接发（浏览器加载它们时带不上令牌，
首页 `no-referrer` 连 Referer 都没有——以前这里要求令牌，页面裸奔过一次，
现由自测验收 6 锁死）。

API 请求要带 `X-Token: <令牌>` 头，或在 query 里带 `t=<令牌>`。
没有令牌一律 403；非回环来源直接拒。

## 跟打包器的接口

控制台 **不 import** 03-bundle 的任何代码，只用子进程调它：

```
python <03-bundle>/install.py   --source <03-bundle>/dist/hubcore --host-home <家目录>
python <03-bundle>/uninstall.py --host-home <家目录> --yes
```

`03-bundle` 的位置由 `bundle_locator.py` 从本文件 `__file__` 往上两级去找。
三个文件（`install.py`、`uninstall.py`、`dist/hubcore`）少任何一个，
载入/卸载都当场报「打包器未就绪」，绝不静默成功。

打包器的输出直接继承终端（`stdio` 用 `inherit`），主人能实时看到它干什么。

## 认得出的智能体

`.codex` `.claude` `.cursor` `.grok` `.gemini` `.deepseek` `.hermes`
`.pi`（优先 `.pi/agent`）**`.omp/agent`** `.dsh` `.zcode` `.config/opencode`
`.windsurf` `.aider` `.pi-desktop`，共 15 家。

> **★ omp 是唯一一家「两文件形态」**：家目录 `~/.omp/agent/` 下
> **没有 `AGENTS.md`** —— 人设在 `PERSONALITY.md`，规则在 `RULES.md`。
> 所以它不走「三段融成一份」，而是**底模卡 → `PERSONALITY.md`，中枢段 + 指引卡 → `RULES.md`**。
> 两个文件各自独立：换底模不动规则，换指引不动人设。实现见 `hosts.py` 的 `entry_base` 字段、
> `server.py` 的 `_direct_text(split_base=True)`、`safebox.py` 的同 tag 整组备份。

「在不在跑」用 `tasklist /FO CSV /NH` 拿镜像名；
node 一类的命令行程序再用一次 CIM 查询拿完整命令行来分辨是哪一家。
两步都读不到时，页面把「载入」置灰并写明「先关掉这家再试」，宁可不装也不冒险。

## 两个只在自测时生效的开关

| 环境变量 | 作用 | 默认 |
|---|---|---|
| `HUBCONSOLE_TEST_HOME` | 多加一个假宿主家目录，必须落在本目录 `TEMP/` 里 | 关 |
| `HUBCONSOLE_BUNDLE_DIR` | 改打包器位置，必须落在本目录 `TEMP/` 里 | 关 |

两个都只认 `TEMP/` 底下的路径，指向别处一律当没设。
正常使用时不需要知道它们存在。
